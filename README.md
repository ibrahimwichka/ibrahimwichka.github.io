# ibrahimwichka.github.io

Personal site. Plain HTML/CSS/JS with no build step, served by GitHub Pages.

- `index.html`: all content
- `assets/css/style.css`: styles and theme tokens (dark default, light toggle)
- `assets/js/main.js`: interactions (accordion, command palette, skills grep, hero canvas)

Local preview:

```bash
python3 -m http.server 4321
```
